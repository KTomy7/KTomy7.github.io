Recent Work

YelpCamp

YelpCamp is a fictional startup that allows users to create and review campgrounds and share it with other users. You must have an account in order to create campgrounds or review them.

PMTRollout Dashboard

This was my bachelor’s thesis project, which is a web application designed to help large organizations manage and monitor multiple projects using interactive Gantt charts.

CleanDesk

CleanDesk is an automated file organizer that keeps your Downloads folder tidy. It monitors files in real time, sorts them into categorized subfolders (like Images, Documents, Videos, Archives, etc.), and can optionally delete old files after a set number of days.

TripTrotters

TripTrotters is a platform where the users can find the best offers, accommodations, and destinations for their holidays. The application serves both individuals looking for accommodations and travel agents who create and sell offers to customers.

TempRadar

TempRadar is a weather monitoring system that provides real-time weather forecasts, air
quality information, and historical weather statistics.
